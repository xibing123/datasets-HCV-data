# datasets-HCV-data
saya akan menjelaskan fungsi fungsi dari EDA, SCALING, MODELING, FEATURE IMPORTANCE, CROSS-VALIDATION

Langkah pertama yang dilakukan dalam proses analisis data ini adalah melakukan *Exploratory Data Analysis* (EDA) atau analisis data eksploratif. EDA bertujuan untuk mengenal lebih jauh isi dataset, misalnya melihat bagaimana distribusi kategori diagnosis seperti pendonor darah, hepatitis, fibrosis, atau sirosis. Ini dilakukan dengan memvisualisasikannya dalam bentuk grafik batang, sehingga kita bisa melihat dengan jelas jumlah pasien di masing-masing kategori. Setelah itu, dibuatlah peta korelasi untuk melihat seberapa besar hubungan antara setiap nilai pemeriksaan laboratorium seperti ALB, ALT, AST, dan lainnya. Korelasi ini membantu kita mengetahui fitur mana saja yang saling berkaitan, misalnya jika dua fitur selalu naik dan turun bersama, artinya mereka memiliki korelasi yang tinggi. Selanjutnya, data perlu dipersiapkan sebelum digunakan dalam model prediksi. Karena nilai-nilai di kolom laboratorium sangat bervariasi (ada yang besar, ada yang kecil), maka dilakukan normalisasi menggunakan *StandardScaler* agar semuanya memiliki skala yang setara. Ini penting supaya algoritma machine learning tidak berat sebelah terhadap fitur tertentu. Setelah data dipersiapkan, dilakukan pelatihan model menggunakan algoritma Random Forest, yang cocok untuk klasifikasi seperti ini karena dapat menangani data dengan banyak fitur dan tidak terlalu sensitif terhadap outlier. Setelah model dilatih, dilakukan pengujian dengan data uji untuk melihat seberapa akurat model tersebut memprediksi kategori pasien. Evaluasi dilakukan dengan menggunakan metrik seperti akurasi, presisi, recall, dan F1-score, yang membantu kita memahami kelebihan dan kekurangan model. Selain itu, juga dianalisis fitur mana saja yang paling berpengaruh dalam proses pengambilan keputusan model, dan hasilnya divisualisasikan dalam grafik batang agar mudah dipahami. Terakhir, agar model tidak hanya baik di satu pembagian data saja, dilakukan *cross-validation*. Ini adalah teknik evaluasi di mana data dibagi menjadi beberapa bagian dan model dilatih serta diuji berulang-ulang pada bagian-bagian yang berbeda. Tujuannya adalah untuk memastikan bahwa model yang dibuat benar-benar handal dan bisa bekerja dengan baik di data baru yang belum pernah dilihat sebelumnya.
